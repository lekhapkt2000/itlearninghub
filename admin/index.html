Nhập nhận xét từ file JSON

Nhận xét được lưu dạng nháp, chưa gửi email. Hệ thống tự khớp tên nhóm, dòng nào chưa khớp thì chọn nhóm bằng tay. Sau khi lưu, mở từng ô để xem trước email rồi gửi.

Nhập bài nộp từ Moodle

Chọn đúng bài, rồi dùng một trong hai cách: (1) Chọn file CSV từ Moodle (View all submissions ➜ Grading action: Download grading worksheet), khớp nhóm theo MSSV. (2) Dán danh sách bài nộp copy từ trang View all submissions (giờ nộp + tên file), khớp nhóm theo tên file; dòng nào chưa khớp thì chọn nhóm bằng tay.
