01 · TỔNG QUAN VỀ CƠ SỞ DỮ LIỆU

Cơ sở dữ liệu là gì?

Cơ sở dữ liệu (Database – CSDL) là tập hợp dữ liệu được tổ chức và lưu trữ theo một cấu trúc nhất định, giúp dữ liệu dễ dàng được quản lý, truy xuất và xử lý.

Trong thực tế, CSDL được sử dụng ở rất nhiều lĩnh vực:

Ngân hàngTài khoản, giao dịch, số dư
Khách sạnKhách hàng, phòng, đặt phòng
Hàng khôngHành khách, chuyến bay, lịch trình
Thư việnSách, độc giả, mượn/trả

Ví dụ

Một trường đại học có thể cần quản lý:

Sinh viên │ ├── Mã sinh viên ├── Họ tên ├── Ngày sinh └── Lớp

Nếu có hàng chục nghìn sinh viên, việc lưu trữ bằng các file rời rạc sẽ khó quản lý. CSDL giúp tổ chức dữ liệu thành các bảng có quan hệ với nhau:

DATABASE: QuanLySinhVien

LOP (1) - Bảng cha
MaLop
TenLop

↓ Quan hệ 1-N: một LOP có nhiều SINHVIEN.

SINHVIEN (N) - Bảng con
MaSV
HoTen
NgaySinh
MaLop (FK)
Lỗi hay gặp khi vẽ sơ đồ: đặt chiều mũi tên ngược, khiến người đọc hiểu nhầm là "1 Sinh viên có nhiều Lớp". Chiều đúng phải đi từ bảng cha xuống bảng con: LOP là bảng cha (giữ khóa chính MaLop), SINHVIEN là bảng con (giữ khóa ngoại MaLop tham chiếu đến LOP) - Một Lớp có nhiều Sinh viên (1-N), không phải ngược lại.

02 · SQL SERVER MANAGEMENT STUDIO

Cài đặt SQL Server Management Studio

Trong phần thực hành, sinh viên sử dụng SQL Server Management Studio (SSMS) để làm việc với SQL Server. Cần chuẩn bị sẵn công cụ thực hành trước buổi học.

Sau khi cài đặt, giao diện SSMS thường được sử dụng để:

  • Kết nối đến SQL Server
  • Tạo Database
  • Tạo Table
  • Viết và thực thi câu lệnh SQL
  • Xem dữ liệu
  • Quản lý các đối tượng trong Database

Quy trình cơ bản

Mở SSMS ↓ Connect đến SQL Server ↓ Chọn / tạo Database ↓ Mở New Query ↓ Viết câu lệnh SQL ↓ Execute ↓ Xem kết quả

Ví dụ câu lệnh đầu tiên

SELECT 'Hello SQL Server';

Kết quả:

Hello SQL Server

03 · KIỂU DỮ LIỆU TRONG SQL

Kiểu dữ liệu trong SQL

Khi tạo một bảng, mỗi cột phải được xác định kiểu dữ liệu - Quy định loại giá trị cột có thể lưu (số, chữ, ngày...) và dung lượng lưu trữ. Chọn đúng kiểu dữ liệu giúp dữ liệu chính xác, tiết kiệm dung lượng và các phép xử lý sau này hoạt động đúng.
SinhVien MaSV ➜ INT HoTen ➜ NVARCHAR(50) NgaySinh ➜ DATE DiemTB ➜ DECIMAL(4,2) DaTotNghiep ➜ BIT

Kiểu số nguyên

BIGINT8 bytePhạm vi rất lớn

Nguyên tắc chọn: Ưu tiên kiểu có phạm vi nhỏ nhất nhưng vẫn đủ chứa dữ liệu thực tế, để tiết kiệm dung lượng lưu trữ. Ví dụ Tuoi (0–150) nên dùng TINYINT thay vì INT.

Kiểu Boolean - BIT

BIT lưu giá trị đúng/sai, thường dùng cho các cột dạng "có/không":

DaTotNghiep BIT

Giá trị lưu trữ: 1 (true), 0 (false) hoặc NULL (chưa xác định).

Kiểu số thực

DECIMAL(p,s)
NUMERIC(p,s)
FLOAT
REAL
MONEY

DECIMAL(p,s) cho phép xác định số chữ số tổng cộng (p) và số chữ số sau dấu phẩy (s). Ví dụ:

DiemTB DECIMAL(4,2)

Có thể lưu: 8.50, 9.25, 10.00

MONEY và SMALLMONEY dùng riêng cho giá trị tiền tệ, chính xác hơn FLOAT/REAL khi tính toán:

DonGia MONEY
Khuyến nghị: Với điểm số, đơn giá, tiền - Ưu tiên DECIMAL(p,s) hoặc MONEY vì cho kết quả chính xác. FLOAT/REAL là số gần đúng, dễ sai lệch khi tính toán nhiều lần.

Kiểu chuỗi

CHAR(n) - Chuỗi có độ dài cố định (luôn chiếm đủ n ký tự, phần dư được đệm khoảng trắng):

MaSV CHAR(8)

Ví dụ giá trị: "23520001"

VARCHAR(n) - Chuỗi có độ dài thay đổi (chỉ chiếm dung lượng đúng bằng số ký tự thực tế):

Email VARCHAR(100)

NCHAR và NVARCHAR - Tương tự CHAR/VARCHAR nhưng lưu chuỗi Unicode, phù hợp khi lưu tiếng Việt có dấu:

HoTen NVARCHAR(50)
DiaChi NVARCHAR(200)

Khi dữ liệu văn bản rất dài (không xác định trước độ dài, ví dụ mô tả sản phẩm), dùng VARCHAR(MAX) hoặc NVARCHAR(MAX) thay vì khai báo số cố định.

04 · DATABASE - CƠ SỞ DỮ LIỆU

Database

Tạo Database

Cú pháp:

CREATE DATABASE <Tên Database>;

Ví dụ:

CREATE DATABASE QuanLySinhVien;

Chọn Database để làm việc

Sau khi tạo Database, sử dụng USE:

USE QuanLySinhVien;

Từ thời điểm này, các câu lệnh tiếp theo sẽ được thực hiện trên Database QuanLySinhVien. Cần kiểm tra Database đang được chọn trong SSMS trước khi thao tác.

Xóa Database

DROP DATABASE QuanLySinhVien;
Cẩn thận: Thao tác này xóa Database và toàn bộ dữ liệu bên trong. Database đang được sử dụng hoặc còn kết nối không thể xóa trực tiếp.

05 · TABLE - BẢNG DỮ LIỆU

Table

Một Table bao gồm Column (thuộc tính của dữ liệu) và Row (một bản ghi). Table là tập hợp các bản ghi có cùng cấu trúc. Ví dụ:

SINHVIEN

MaSVHoTenNgaySinh
1Nguyễn Văn An2004-05-20
2Trần Thị Bình2004-08-15
3Lê Văn Cường2004-11-02

Tạo Table

Cú pháp cơ bản:

CREATE TABLE <Tên Table>
(
    <Tên cột 1> <Kiểu dữ liệu>,
    <Tên cột 2> <Kiểu dữ liệu>,
    ...
);

Ví dụ:

CREATE TABLE SinhVien
(
    MaSV INT,
    HoTen NVARCHAR(50),
    NgaySinh DATE,
    Lop NVARCHAR(20)
);

KIỂM TRA NHANH

Câu lệnh nào dùng để tạo một Table?

✓ Chính xác! CREATE TABLE được dùng để tạo một bảng trong Database.

Xóa Table

DROP TABLE SinhVien;
Khi Table bị xóa, dữ liệu bên trong cũng bị xóa. Không thể xóa một Table nếu đang có Foreign Key từ Table khác tham chiếu đến nó.

ALTER TABLE

ALTER TABLE dùng để thay đổi cấu trúc của Table sau khi đã tạo.

Thêm cột

ALTER TABLE SinhVien
ADD Email NVARCHAR(100);

Xóa cột

ALTER TABLE SinhVien
DROP COLUMN Email;

Thay đổi kiểu dữ liệu

ALTER TABLE SinhVien
ALTER COLUMN NgaySinh DATE;

06 · RÀNG BUỘC TOÀN VẸN - CONSTRAINTS

Constraints

Constraint giúp đảm bảo dữ liệu trong Database tuân thủ các quy tắc nhất định.

Các ràng buộc quan trọng trong Tuần 1:

PRIMARY KEY FOREIGN KEY UNIQUE NOT NULL CHECK DEFAULT

PRIMARY KEY

Khóa chính dùng để xác định duy nhất một bản ghi trong Table.

CREATE TABLE SinhVien
(
    MaSV INT PRIMARY KEY,
    HoTen NVARCHAR(50),
    NgaySinh DATE
);

Khi đó không được phép có hai sinh viên cùng MaSV.

NOT NULL

NOT NULL yêu cầu cột phải có giá trị.

CREATE TABLE SinhVien
(
    MaSV INT PRIMARY KEY,
    HoTen NVARCHAR(50) NOT NULL,
    NgaySinh DATE
);

Câu lệnh sau sẽ không hợp lệ vì HoTen được khai báo NOT NULL:

INSERT INTO SinhVien
VALUES (1, NULL, '2004-05-20');

UNIQUE

Đảm bảo giá trị trong cột không bị trùng.

CREATE TABLE SinhVien
(
    MaSV INT PRIMARY KEY,
    Email NVARCHAR(100) UNIQUE
);
SV001 ➜ kha@uit.edu.vn SV002 ➜ kha@uit.edu.vn ✗ trùng

FOREIGN KEY

FOREIGN KEY dùng để tạo mối liên hệ giữa các bảng. Ví dụ có hai bảng:

LOP

MaLopTenLop
1HTTT2022.1
2HTTT2022.2

↑ SINHVIEN.MaLop tham chiếu đến LOP.MaLop.

SINHVIEN

MaSVMaLop
1011
1021
1032
CREATE TABLE Lop
(
    MaLop INT PRIMARY KEY,
    TenLop NVARCHAR(50)
);

CREATE TABLE SinhVien
(
    MaSV INT PRIMARY KEY,
    HoTen NVARCHAR(50),
    MaLop INT,

    FOREIGN KEY (MaLop)
        REFERENCES Lop(MaLop)
);

Khi đó, câu lệnh sau sẽ bị từ chối nếu 999 không tồn tại trong Lop.MaLop:

INSERT INTO SinhVien
VALUES (101, N'Nguyễn Văn An', 999);

Khóa ngoại phải được thiết lập ở Table chứa khóa ngoại.

CHECK

CHECK dùng để giới hạn dữ liệu phải thỏa một điều kiện. Ví dụ điểm sinh viên phải từ 0 đến 10:

CREATE TABLE KetQua
(
    MaSV INT,
    Diem DECIMAL(4,2),

    CHECK (Diem >= 0 AND Diem <= 10)
);
INSERT INTO KetQua
VALUES (101, 8.5);

✓ Hợp lệ. Nhưng:

INSERT INTO KetQua
VALUES (102, 15);

✗ Không hợp lệ.

DEFAULT

DEFAULT cung cấp giá trị mặc định nếu người dùng không nhập giá trị.

CREATE TABLE SinhVien
(
    MaSV INT PRIMARY KEY,
    HoTen NVARCHAR(50),
    GioiTinh CHAR(1) DEFAULT 'M'
);

Nếu:

INSERT INTO SinhVien(MaSV, HoTen)
VALUES (101, N'Nguyễn Văn An');

thì SQL Server tự động đặt GioiTinh = 'M'.

Khai báo nhiều Constraint

Có thể kết hợp nhiều ràng buộc - Kiểu dữ liệu và ràng buộc luôn đi cùng nhau khi thiết kế Table:

CREATE TABLE SinhVien
(
    MaSV INT PRIMARY KEY,

    HoTen NVARCHAR(50) NOT NULL,

    Email NVARCHAR(100) UNIQUE,

    MaLop INT
        FOREIGN KEY REFERENCES Lop(MaLop),

    NgaySinh DATE
        CHECK (NgaySinh >= '1900-01-01'),

    GioiTinh CHAR(1)
        DEFAULT 'M'
);

07 · THAO TÁC DỮ LIỆU - DML

Data Manipulation Language

DML (Data Manipulation Language) là nhóm lệnh dùng để thao tác với dữ liệu trong Table.

Trong Tuần 1, sinh viên làm quen với:

INSERT ➜ Thêm dữ liệu DELETE ➜ Xóa dữ liệu UPDATE ➜ Cập nhật dữ liệu SELECT INTO ➜ Sao chép dữ liệu

INSERT - Thêm dữ liệu

Cách 1: Không chỉ định tên cột

INSERT INTO SinhVien
VALUES (101, N'Nguyễn Văn An', '2004-05-20', N'HTTT2022.1');

Cách 2: Chỉ định tên cột - nên ưu tiên cách này, vì câu lệnh rõ ràng hơn và ít phụ thuộc vào thứ tự cột.

INSERT INTO SinhVien
(
    MaSV,
    HoTen,
    NgaySinh,
    Lop
)
VALUES
(
    101,
    N'Nguyễn Văn An',
    '2004-05-20',
    N'HTTT2022.1'
);

Có thể thêm nhiều bản ghi trong một câu lệnh:

INSERT INTO SinhVien
VALUES
    (101, N'Nguyễn Văn An', '2004-05-20', N'HTTT2022.1'),
    (102, N'Trần Thị Bình', '2004-08-15', N'HTTT2022.1'),
    (103, N'Lê Văn Cường', '2004-11-02', N'HTTT2022.2');

Sau đó kiểm tra:

SELECT *
FROM SinhVien;

DELETE - Xóa dữ liệu

DELETE FROM <Tên bảng>
WHERE <Điều kiện>;

Ví dụ - Chỉ sinh viên có MaSV = 101 bị xóa:

DELETE FROM SinhVien
WHERE MaSV = 101;
Cực kỳ quan trọng: Nếu không có WHERE -
DELETE FROM SinhVien;
➜ tất cả các dòng trong bảng sẽ bị xóa.

UPDATE - Cập nhật dữ liệu

UPDATE <Tên bảng>
SET <Cột 1> = <Giá trị mới>
WHERE <Điều kiện>;
UPDATE SinhVien
SET HoTen = N'Nguyễn Văn Nam'
WHERE MaSV = 101;

Có thể cập nhật nhiều cột cùng lúc:

UPDATE SinhVien
SET
    HoTen = N'Nguyễn Văn Nam',
    Lop = N'HTTT2022.2'
WHERE MaSV = 101;

SELECT INTO - Sao chép dữ liệu

SELECT INTO cho phép tạo một Table mới từ kết quả truy vấn.

SELECT *
INTO SinhVien_Backup
FROM SinhVien;
SINHVIEN ↓ SELECT INTO ↓ SINHVIEN_BACKUP

Nếu chỉ muốn sao chép một phần dữ liệu:

SELECT *
INTO SinhVien_HTTT
FROM SinhVien
WHERE Lop LIKE 'HTTT%';
