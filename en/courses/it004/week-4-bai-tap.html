QUESTION 1 (SAMPLE) · CASE WHEN

Classify members by number of sessions

Exercise: Label members: fewer than 5 sessions is "Mới", 5-20 sessions is "Thường xuyên", over 20 sessions is "Tích cực".

SELECT HoTen,
    CASE
        WHEN SoBuoiTap < 5 THEN N'Mới'
        WHEN SoBuoiTap <= 20 THEN N'Thường xuyên'
        ELSE N'Tích cực'
    END AS PhanLoai
FROM HocVien;
WHAT IS IT?

CASE WHEN is a conditional expression that returns different values depending on the condition, used directly inside SELECT.

WHY?

Rows need to be labeled based on several different value ranges right within each row - CASE WHEN handles this neatly in 1 statement, instead of running multiple separate UPDATE/IF statements.

QUESTION 2 (SAMPLE) · SUBQUERY

Members training above the average

Exercise: Find the members whose number of sessions is higher than the average number of sessions across all members.

SELECT HoTen, SoBuoiTap
FROM HocVien
WHERE SoBuoiTap > (
    SELECT AVG(SoBuoiTap) FROM HocVien
);
WHAT IS IT?

A subquery placed in parentheses; here it returns exactly 1 value (the average) for the outer query to compare against in WHERE.

WHY?

The average value must be computed first - you can't compute AVG and compare it against each row within the same SELECT at once, so it has to be split into a subquery that runs first.
