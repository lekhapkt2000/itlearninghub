QUESTION 1 (SAMPLE) · JOIN + GROUP BY + ORDER BY

Exercise: Which supplier shipped the most parts? Show the supplier name and quantity of parts shipped.

SELECT TOP 1 WITH TIES ncc.TENNCC, SUM(vc.SOLUONG) AS TongSoLuong
FROM NHACUNGCAP ncc
JOIN VANCHUYEN vc ON ncc.MANCC = vc.MANCC
GROUP BY ncc.TENNCC
ORDER BY TongSoLuong DESC;
WHAT IS IT?

Combines JOIN (to get the supplier name), GROUP BY (to total the quantity per supplier), and ORDER BY ... DESC + TOP 1 (to take the supplier with the most).

WHY?

This is a typical example of chaining several learned techniques together: you must JOIN first to get the name, GROUP BY to total per supplier, and only then sort and take the first row - doing the steps out of order produces a wrong result or a syntax error.

QUESTION 2 (SAMPLE) · INSERT + UPDATE

Exercise: Write the SQL statement to insert a new supplier: S6, Duncan, 30, Paris. Then change S6's city to Sydney.

INSERT INTO NHACUNGCAP (MANCC, TENNCC, TRANGTHAI, THANHPHO)
VALUES ('S6', 'Duncan', 30, 'Paris');

UPDATE NHACUNGCAP
SET THANHPHO = 'Sydney'
WHERE MANCC = 'S6';
WHAT IS IT?

INSERT adds 1 new supplier row; UPDATE ... WHERE MANCC = 'S6' only modifies the row just added.

WHY?

The WHERE clause in UPDATE must filter to the exact MANCC - forgetting WHERE would change every supplier in the table to "Sydney."
